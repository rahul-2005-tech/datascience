# Data Science Mini Projects

## Overview

This repository contains a collection of beginner-friendly Data Science and Python projects developed using Jupyter Notebook and Google Colab. The projects focus on practical implementation of data analysis, visualization, statistical operations, business analytics, and Object-Oriented Programming concepts using real-world datasets and problem-solving approaches.

The main objective of this repository is to strengthen Python programming and Data Science fundamentals through hands-on mini projects.

## 6. Coffee Machine (Object-Oriented Programming Project)

A console-based Coffee Machine application developed using Object-Oriented Programming concepts in Python. The project demonstrates abstraction, inheritance, encapsulation, and polymorphism using multiple coffee types and preparation processes.

### Key Features

- Interactive menu-driven coffee selection
- Multiple coffee varieties:
  - Espresso
  - Americano
  - Latte
  - Cappuccino
  - Mocha
  - Frappe
- Abstract base class implementation using Python's `abc` module
- Encapsulation through private attributes
- Inheritance for extending coffee types
- Polymorphism using method overriding
- Modular and reusable OOP design

### OOP Concepts Demonstrated

- Classes and Objects
- Abstraction
- Inheritance
- Encapsulation
- Polymorphism
- Method Overriding
- Constructors (`__init__`)

### Technologies Used

- Python
- Object-Oriented Programming (OOP)
- ABC (Abstract Base Classes)

### Learning Outcomes

- Understanding real-world OOP implementation
- Creating reusable class hierarchies
- Working with abstract classes and methods
- Building modular Python applications
